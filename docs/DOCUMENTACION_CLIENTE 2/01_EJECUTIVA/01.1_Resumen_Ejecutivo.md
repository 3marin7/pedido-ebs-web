## Qué es el producto

EBS es una aplicación web de una sola página desarrollada con React y Vite. Utiliza Supabase como servicio externo de autenticación y acceso a datos. La aplicación contiene módulos para operación comercial, inventario, cartera, catálogo, reportes y administración; el acceso interno se controla en la interfaz mediante sesión y roles.

La aplicación está preparada para ejecutarse como sitio web y puede configurarse con las variables `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`. El repositorio no identifica el proveedor, la región ni el plan del servicio de producción.

## Funcionalidad presente en el código

- Facturación y consulta de facturas, detalles y abonos.
- Gestión de clientes, productos, pedidos e inventario, con movimientos y auditoría.
- Catálogo público y catálogo con precio de detalle; preventa de productos.
- Campañas de catálogo y apertura de mensajes de WhatsApp para compartir o contactar clientes.
- Rutas de cobro, informes de ventas/cobros y paneles de análisis.
- Cuentas por pagar, gastos y pantallas de contabilidad.
- Herramientas adicionales: consulta local de catálogo Coopidrogas, mapa de locales, gestión de inmuebles y plataformas, verificación de facturas físicas, plan de seguimiento de ventas, calculador de sueldo y juegos.
- Exportación o generación de documentos en algunos flujos, según el módulo.

La lista anterior acredita componentes y flujos de aplicación existentes en el código; no constituye una certificación de que todas las funciones, datos, permisos o integraciones estén operativos en el ambiente de entrega.

## Conectividad y seguridad: alcance comprobable

- La autenticación se apoya en Supabase Auth y los perfiles/roles se consultan desde `user_profiles`.
- Hay rutas públicas de catálogo y rutas internas protegidas por sesión y roles en la aplicación.
- El service worker de Vite PWA almacena en caché recursos estáticos e imágenes. Además, hay almacenamiento local y cola de sincronización para pedidos. Esto no equivale a operar todo el sistema sin conexión: la consulta y escritura general de datos requiere conexión con Supabase.
- WhatsApp se abre mediante enlaces/mensajes desde el navegador; el código revisado no acredita una API oficial de WhatsApp Business ni envío automatizado en segundo plano.
- El código contiene llamadas de carga a Cloudinary en ciertos flujos. La disponibilidad y configuración de la cuenta deben comprobarse en el ambiente final.
- El repositorio no permite confirmar políticas RLS de la base de datos, cifrado/SSL del despliegue, respaldos configurados, retención, monitoreo, disponibilidad ni recuperación ante desastres. Estos puntos requieren verificación en las consolas y contratos de los servicios.

## Límites importantes

- La aplicación registra y consulta facturas comerciales. No se encontró evidencia en este repositorio de integración de facturación electrónica, autorización, firma o transmisión de documentos ante la DIAN.
- No hay evidencia suficiente para afirmar cumplimiento legal, resultados financieros, reducción de pérdidas, porcentaje de ahorro, tiempos de respuesta o retorno de inversión.
- Las cifras de pérdidas, ahorros, inversión, usuarios capacitados y cronograma de versiones anteriores no estaban sustentadas por datos o acuerdos presentes en el repositorio; por ello no se reproducen como hechos.
- El proyecto no incluye en el repositorio un esquema versionado completo de base de datos que permita certificar la estructura ni los datos del ambiente Supabase conectado.

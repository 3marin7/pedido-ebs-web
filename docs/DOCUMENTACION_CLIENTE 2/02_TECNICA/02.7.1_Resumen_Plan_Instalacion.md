# Resumen del plan de instalación
## Sistema EBS

**Revisión:** 21 de octubre de 2026
**Estado:** pasos propuestos; ambiente de entrega pendiente de confirmar

> Este resumen no certifica que EBS esté desplegado ni que la instalación esté aprobada. El repositorio no identifica hosting, dominio, región/plan de Supabase ni cuentas contratadas. Se eliminan costos, fechas y compromisos no respaldados por evidencia del proyecto o contrato.

## Qué contiene el repositorio

- Aplicación frontend React 18 compilada con Vite 7.
- Scripts para desarrollo, build, preview, lint y pruebas.
- Integración cliente con Supabase, configurada con `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`.
- Configuración PWA y soporte local limitado para catálogo/pedidos.

## Preparación requerida para un despliegue

1. Identificar proveedor de hosting, dominio y responsables de las cuentas.
2. Confirmar el proyecto Supabase, esquema, políticas RLS y datos de prueba aprobados.
3. Configurar exclusivamente variables públicas necesarias para el bundle; no incluir claves de servicio privilegiadas en variables `VITE_`.
4. Ejecutar `npm run build`, pruebas y revisión de permisos antes del despliegue.
5. Validar rutas, catálogo, autenticación, roles, operaciones principales, errores y modo offline parcial en el ambiente objetivo.
6. Registrar URL, versión/tag desplegada, resultado de aceptación, procedimiento de reversión y responsables.

## Pendientes comerciales y operativos

Hosting, dominio, servicios de terceros, migración, capacitación, soporte, backups, costos y cronograma no se incluyen hasta que se definan y aprueben por separado. El plan detallado `02.7_Plan_Instalacion.md` también es un borrador: ajustar sus comandos, servicios y valores al entorno real antes de ejecutarlo.

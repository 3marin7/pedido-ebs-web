# Notas para presentar EBS

**Revisión:** 21 de octubre de 2026
**Estado:** guía para una presentación nueva; el PPTX existente sigue pendiente de actualización.

## Apertura

“Gracias por el espacio. Queremos mostrar las funciones disponibles en el código de EBS y entender cuáles responden a sus procesos. Aún debemos confirmar el ambiente y los criterios de aceptación.”

## Contexto

“Antes de hablar de beneficios, queremos conocer cómo registran ventas, pedidos, inventario y cartera. No contamos aquí con cifras verificadas de pérdidas o tiempos.”

## Demostración

“Esta es la versión/build que estamos demostrando. Las pantallas dependen de la configuración y los datos del proyecto Supabase. Usaremos datos de prueba.”

## Arquitectura y conectividad

“El frontend usa React/Vite y se comunica con Supabase. Algunas pantallas abren enlaces de WhatsApp. Existe almacenamiento local para algunos recursos y pedidos; la operación general requiere conexión. El proveedor de hosting, las políticas RLS y los backups se deben confirmar por separado.”

## Alcance fiscal y comercial

“La aplicación gestiona facturas comerciales, pero no tenemos evidencia de integración DIAN en este repositorio. No presentaremos ahorro, ROI, precio, plazo, soporte o disponibilidad como comprometidos hasta tener datos validados y un acuerdo formal.”

## Cierre

“El siguiente paso sería acordar módulos, ambiente, roles, datos de prueba y casos de aceptación. Después se puede preparar una cotización que defina precio, responsabilidades, cronograma y soporte.”

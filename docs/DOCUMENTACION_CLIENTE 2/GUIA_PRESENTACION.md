# Guía de presentación del sistema EBS

**Revisión:** 21 de octubre de 2026
**Uso:** guion para presentar capacidades verificables; no constituye oferta.

> El guion anterior afirmaba pérdidas, ROI, tarifas, hosting, backups y garantías sin soporte documental. No repetir esas cifras. El archivo `05_PRESENTACION/Presentacion_EBS.pptx` y `generar_pptx.py` siguen conteniendo material histórico no verificado; no distribuir ni regenerar hasta actualizarlos.

## Antes de la reunión

- Confirmar quién asiste y qué necesidad quiere resolver.
- Preparar una demostración con datos de prueba que no identifiquen personas reales.
- Confirmar qué build y qué ambiente se mostrarán y si las integraciones están configuradas.
- Llevar la [base comercial](./01_EJECUTIVA/01.2_Propuesta_Comercial.md) como documento no vinculante.

## Guion sugerido

1. **Contexto:** preguntar cómo se gestionan hoy ventas, cartera, pedidos e inventario. No asumir pérdidas ni procesos manuales.
2. **Demostración:** mostrar, con datos sintéticos, módulos presentes en el código: catálogo, facturas, pedidos/inventario y reportes relevantes para la audiencia.
3. **Límites:** explicar que las funciones dependen de datos y configuración Supabase; el modo offline es parcial y no reemplaza la conectividad general.
4. **Integraciones:** describir WhatsApp como apertura de enlaces desde el navegador; no afirmar automatización/API oficial. No afirmar DIAN salvo evidencia separada.
5. **Validación:** acordar qué flujos, roles, volumen y controles de seguridad se probarán para aceptar la entrega.
6. **Oferta:** completar costos, servicios, cronograma, soporte, backup y obligaciones en documento/contrato aprobado, después del levantamiento.

## Frases seguras

- “El repositorio contiene una aplicación React conectada a Supabase; confirmemos juntos el ambiente que se entregaría.”
- “El código incluye estos módulos; la disponibilidad y aceptación se demostrarán con pruebas en el ambiente acordado.”
- “No tengo una cifra validada de ahorro o retorno; podríamos calcularla con su línea base real.”
- “Hosting, backups, soporte, precios y calendario quedan por definir en una oferta formal.”
